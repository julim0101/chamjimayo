# 법령·판례 코퍼스 수집 가이드

담당: **다영 (RAG 구축)**

---

## 현재 적재 상태

| 파일 | 건수 | 상태 |
|------|------|------|
| `statutes.jsonl` | 18 | 조문 초안 적재 — **원문 대조 검증 필요** |
| `moel_manual.jsonl` | 12 | 매뉴얼 판단기준·행위유형 초안 — **원문 대조 검증 필요** |
| `precedents.jsonl` | 0 | **미수집 (템플릿만 있음)** |

> ⚠️ 모든 레코드의 `verified` 필드가 현재 `false`입니다.
> 원문과 대조한 뒤 `true`로 바꿔주세요. 앱은 `verified: false` 인용에
> "미검증" 배지를 붙여 표시합니다. 심사 시연 전까지 `true`로 만드는 것이 목표입니다.

## 1. 법령 원문 검증 (최우선)

출처: **국가법령정보센터** <https://www.law.go.kr>

1. 「근로기준법」 검색 → 조문별로 `statutes.jsonl`의 `text`와 한 글자씩 대조
2. 특히 확인이 필요한 항목
   - 제76조의2 — 성립요건 문구 (본 서비스의 핵심 근거)
   - 제76조의3 제5항·제6항 — 항 번호와 내용 일치 여부
   - 제116조 — 과태료 금액 및 대상 조항 번호
   - 제109조 — 벌칙 대상 조항 및 형량
   - 제56조 — 가산율(50/100, 100/100) 및 야간근로 시간대
3. 개정 이력이 있으면 **시행일 기준 최신본**으로 맞추고 `text` 끝에
   `(시행 YYYY.MM.DD.)` 를 덧붙입니다.

법령 API를 쓰면 자동화도 가능합니다 (오픈API 신청 필요):
`https://www.law.go.kr/DRF/lawService.do?OC=<ID>&target=law&MST=<법령ID>&type=JSON`

## 2. 고용노동부 매뉴얼 검증

출처: **고용노동부 자료실** <https://www.moel.go.kr> → 정책자료 → 직장 내 괴롭힘

- 「직장 내 괴롭힘 판단 및 예방·대응 매뉴얼」 최신판 PDF 다운로드
- `moel_manual.jsonl`의 각 레코드를 해당 페이지와 대조
- `source_doc` 필드에 **판 번호와 발간 연월**을 명시 (예: `2023년 개정판, p.14`)
- 매뉴얼에만 있고 우리 코퍼스에 빠진 행위유형이 있으면 레코드를 추가

## 3. 판례 수집 (미착수)

출처
- **대법원 종합법률정보** <https://glaw.scourt.go.kr>
- **국가법령정보센터 판례** <https://www.law.go.kr/판례>
- **중앙노동위원회 판정례** <https://www.nlrc.go.kr>

### 검색 키워드

```
직장 내 괴롭힘          근로기준법 제76조의2
업무상 적정범위          지위 또는 관계의 우위
직장 내 괴롭힘 손해배상   직장 내 괴롭힘 산재
괴롭힘 신고 불이익 처우   태움
```

### 수집 시 지켜야 할 것

1. **원문 그대로 붙여넣기.** 요약·의역 금지.
   RAG의 존재 이유가 "환각 없이 출처를 인용하는 것"인데,
   코퍼스 자체가 의역이면 그 전제가 무너집니다.
2. **사건번호를 반드시 확인.** 기억이나 추측으로 채우지 마세요.
   확인 안 된 사건번호가 리포트에 인용되면 서비스 신뢰도가 통째로 무너집니다.
3. `holding`에 법리를 한 문장으로 정리 — 이건 우리가 쓰는 요약이므로
   `text`(원문)와 명확히 분리해 둡니다.
4. `maps_to`에 3요건 중 어디에 해당하는지 표시 (`R1`/`R2`/`R3`).

### 목표 분량

| 유형 | 목표 |
|------|------|
| 성립요건 판단 법리 (R1/R2/R3) | 각 3건 이상 |
| 손해배상 인정 사례 | 3건 |
| 산재 인정 사례 | 2건 |
| 신고 후 불이익 처우 | 2건 |
| **합계** | **16건 이상** |
